# Troubleshooting

<div class="kr-eyebrow">Support</div>

## Zanim zgłosisz problem

1. Sprawdź, czy wszystkie zależności uruchamiają się przed resource'em.
2. Sprawdź konsolę serwera pod kątem pierwszego błędu w stack trace.
3. Sprawdź konsolę F8 klienta.
4. Zweryfikuj wykonanie wymaganych migracji SQL.
5. Sprawdź, czy używasz wersji dokumentacji odpowiadającej wersji skryptu.

## Co dołączyć do zgłoszenia

```text
Resource:
Version:
Framework:
Dependencies:
Server error:
Client F8 error:
Steps to reproduce:
```

::: danger Sekrety
Przed wysłaniem logów usuń license keys, tokeny, hasła, webhooki i inne sekrety.
:::
