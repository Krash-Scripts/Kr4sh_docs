# Dla developerów

<div class="kr-eyebrow">Developer API</div>

Ta część dokumentacji zbiera publiczne punkty integracji resource'ów KR4SH.

## Standard wpisu API

Każdy publiczny event lub export będzie zawierał:

- informację **Client / Server**,
- sygnaturę,
- opis parametrów,
- zwracaną wartość,
- przykład użycia,
- informacje o wymaganiach i ograniczeniach.

## Stabilność API

Elementy oznaczone jako publiczne są przeznaczone do używania przez inne resource'y. Wewnętrzne funkcje nie będą dokumentowane jako część stabilnego API.
