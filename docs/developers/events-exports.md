# Events & Exports

<div class="kr-eyebrow">Integration reference</div>

Ta strona będzie indeksem publicznych eventów i exportów ze wszystkich resource'ów.

## Format przykładu

```lua
-- Client example
local result = exports['resource_name']:exampleExport()
```

Każdy wpis będzie jasno wskazywał kontekst wykonania oraz typy parametrów.

::: warning Zweryfikowane API only
Nie dodajemy do dokumentacji eventów znalezionych w starych buildach, logach lub pamięci. Publiczne API musi zostać potwierdzone w aktualnym source.
:::
