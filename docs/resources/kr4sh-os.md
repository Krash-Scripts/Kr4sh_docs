# KR4SH OS

<div class="kr-eyebrow">Flagship resource</div>

Dokumentacja systemu telefonu KR4SH OS: instalacja, aplikacje, konfiguracja, integracje oraz API dla innych resource'ów.

::: info Status
Struktura jest gotowa. Szczegółowe API zostanie dodane po analizie aktualnego wydania telefonu.
:::

## Zakres dokumentacji

- instalacja i wymagania,
- konfiguracja telefonu,
- aplikacje i ich moduły,
- integracje z inventory, voice i mediami,
- publiczne events i exports,
- procedury aktualizacji,
- troubleshooting.

## Installation

Pełna procedura zostanie przygotowana na podstawie aktualnego `fxmanifest.lua`, configu oraz migracji SQL.

## Developer API

Nie publikujemy nazw eventów ani exportów, dopóki nie zostaną zweryfikowane względem aktualnego kodu.
