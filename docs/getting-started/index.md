# Getting Started

<div class="kr-eyebrow">Start here</div>

KR4SH Docs to centralna dokumentacja wszystkich publicznych interfejsów i procedur instalacji resource'ów KR4SH.

## Jak korzystać z dokumentacji

1. Otwórz **Skrypty** i wybierz resource.
2. Sprawdź wymagania oraz zależności przed instalacją.
3. Wykonaj kroki instalacyjne w podanej kolejności.
4. Skonfiguruj resource i wymagane integracje.
5. Jeżeli korzystasz z API, przejdź do sekcji **Events & Exports**.

## Zasada wersji

Dokumentacja API powinna odpowiadać wersji resource'u, którego używasz. Przy zmianach breaking zostanie to wyraźnie zaznaczone w changelogu.

## Potrzebujesz instalacji?

Przejdź do [instrukcji instalacji](/getting-started/installation).
